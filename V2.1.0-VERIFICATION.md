## Changes and cleanup

- Settings provide a drawn left arrow plus Back, with tooltip/accessibility label
  “Back to clipboard history”. It returns to the main list, preserving search/filter
  state. The vector arrow works with fonts missing the Unicode arrow glyph.
- Narrow windows/larger font zoom wrap navigation above the content. Wider windows
  use a sidebar. Content uses the remaining width; a solid 8-point scrollbar reserves
  space for itself and sits 6 points from the right edge, with a 4-point inner gap.
  Appearance controls and descriptions wrap; the font chooser fits available width.
- Pinned rows use a larger 22-point filled pin with theme-specific accent color;
  unpinned rows use an 18-point muted outline. Pin clip / Unpin clip labels identify
  the action. Selected/unselected light/dark icon contrast is tested at >=3:1.
- Clear unpinned uses the complete store, including clips hidden by search/filters.
  Active filters show its global scope. It disables when no unpinned clips remain,
  follows Confirm before deleting, and uses “Delete all unpinned clips? Pinned clips
  will be kept.” with Cancel / Delete unpinned. Pins remain after deletion/reopen.
- Removed duplicate clear-action handling and repeated settings JSON serialization;
  release retained text/image/list resources after successful bulk clear. The old
  RPM path that packaged a prebuilt Ubuntu binary was replaced with Fedora source
  compilation. Shared asset installation replaces the former inline RPM staging copy.
- All 14 direct Rust dependencies and X11 feature flags have source callers; no
  dependency or required asset was removed. Migration, notices, polling cadence,
  automatic paste, clipboard backends and desktop shortcut integrations are retained.
- Cargo.toml/normal-tool-regenerated Cargo.lock, About/CLI version, changelog,
  AppStream, release notes, README and website release metadata use 2.1.0.
  Historical release entries, measurements and v2.0 screenshot provenance retain
  their true versions. Website light/dark/system logic remains unchanged.
